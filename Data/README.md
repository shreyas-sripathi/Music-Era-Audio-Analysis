## How to Use
1. Clone this repository
2. Install dependencies: `pip install pandas numpy scipy matplotlib seaborn`
3. Run `notebooks/01_eda.ipynb`
4. See `ANALYSIS.md` for detailed findings

## Key Insight
Modern Spotify hits prioritize **groove and positivity** over raw speed or energy.

## Technical Details
- **Statistical Tests**: Independent samples t-tests (α = 0.05)
- **Sample Size**: 50 songs (2025) + 100 songs (all-time)
- **Effect Size Metric**: Cohen's d

See `ANALYSIS.md` for complete methodology and results.
